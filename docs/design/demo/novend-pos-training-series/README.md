# Training series masters (local edit workspace)

**Live on `/demo` under “Per action”.**  
The merged full walkthrough is `../novend-pos-complete-training.mp4` (main player).

## Publish an episode

1. Keep the numbered filename (`NN-novend-<topic>.mp4`).
2. Copy to:

```text
public/marketing/demo/training/<same-filename>.mp4
```

3. Confirm `landingCopy.demoPage.episodes` in `features/marketing/content.ts`
   (`id`, `order`, `src`, label, description).

Video posters use `/branding/brandmark.png` (Novend logo). The collage
`novend-training-series-preview.jpg` is optional reference art only — not served.

Media in this folder is gitignored; only this README (and `.gitignore`) is tracked.
Full id map and current status: [`../README.md`](../README.md).
