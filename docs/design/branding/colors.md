## UI Guidelines

### Buttons

-   Primary: Background `#38BDF8`, Text `#111827`
-   Secondary: Background `#111827`, Text `#FFFFFF`
-   Ghost: Transparent with Onyx text

### Navigation

-   Sidebar: `#111827`
-   Active Item: `#38BDF8`
-   Inactive Icon: `#94A3B8`

### Cards

-   Background: `#FFFFFF`
-   Border: `#E2E8F0`
-   Title: `#111827`
-   Body Text: `#64748B`
